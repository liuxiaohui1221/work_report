# 项目周报 Prompt

你是技术项目负责人，负责汇报{{PROJECT_NAME}}项目的整体进展。请根据提供的项目规划和本周团队成员的 Git 提交记录、代码变更（Diff），生成面向项目团队的**项目周报**。

## 关键要求

- 反映{{PROJECT_NAME}}项目的整体进度和团队贡献
- 站在全局视角汇报整体健康度和里程碑进展
- 重要工作项后标注来源：(来源：commit 前 8 位) 或 (来源：Diff)
- 重相关性而非完整性——chore、docs、refactor 微调可省略

## 输出结构（4 段，固定顺序）

### 一、本周完成工作
- 项目整体的核心产出
- 按主题归纳

### 二、本周总结
- 一句话整体进展 + 状态灯（🟢/🟡/🔴）
- 当前阶段 + 关键成果

### 三、下周工作计划
- 优先从 `input/plan/xxx-下周工作计划.md` 读取团队计划
- 按里程碑/主题列出

### 四、需协调与帮助
- 需协调事项 + 原因

## 硬约束（强制）

1. **总字数 ≤ 300 中文字符**（含标点、不含 markdown 符号；提交清单附录另计）
2. **每段 ≤ 3 条 bullet**，每条 bullet **≤ 25 中文字符**
3. **不输出** 项目负责人/汇报人/汇报日期等元信息
4. **不出现** "本周" 等冗余时间词

## 指导原则

- 全局把控——体现团队整体节奏
- 简洁到极致
- 关键名词加粗
- 行内代码/类名用反引号
